# finance-analytics-dashboard

📊 Project Overview

This project is an interactive Finance Analysis Dashboard developed using Power BI. The dashboard provides insights into financial transactions, customer behavior, revenue trends, fees, taxes, and transaction performance through dynamic visualizations and filters.

🎯 Objectives
- Analyze financial transaction data efficiently.
- Monitor key financial KPIs.
- Track customer segments and transaction status.
- Identify trends and patterns in financial performance.
- Enable data-driven decision making.

✨ Key Features
- KPI Cards – Total Amount, Total Transactions, Avg Transaction Value, Total Fees, and Total Tax with year-over-year comparison
- Monthly Trend Chart – Visualizes total amount fluctuations across all 12 months
- Transaction Status Breakdown – Donut chart showing Success, Failed, and Pending split
- State-wise Analysis – Horizontal bar chart ranking top states by transaction volume
- Transaction Type Analysis – Table view with Amount, Fees, Tax, and Transaction count per type
- Customer Segment Analysis – Retail, Premium, SME, Corporate, and Wealth segments compared
- Gender Distribution – Male vs Female split across total transaction amount
- Transactions Detail Page – Granular row-level transaction data with filters

🔍 Key Insights
- Revenue trends can be analyzed monthly and yearly.
- Customer segments contribute differently to total revenue.
- Most transactions are completed successfully.
- State-wise analysis helps identify high-performing regions.
- Gender and transaction type analysis provide customer behavior insights.

🛠️ Tools & Technologies
- Power BI Desktop – Dashboard development
- DAX – Calculated measures and KPIs
- Power Query – Data transformation and cleaning

 📈Business Impact & Insights
- Revenue Monitoring – Track total amount (₹135.62M) and YoY changes to quickly identify negative trends (-1.06%) and take corrective action.  
- Customer Segment Focus – Retail contributes the highest (₹26M), enabling targeted campaigns for Premium (₹21M) and SME (₹9M) growth.  
- Geographic Prioritisation – Maharashtra (₹19.7M) and Karnataka (₹15.8M) are top revenue states; low-performing states like Delhi (₹7.3M) and Kerala (₹8.0M) can be addressed with region‑specific strategies.  
- Transaction Type Optimisation – Loan EMI (₹39.9M) and Transfer (₹35.7M) dominate volumes; analysing fees/tax per type helps improve pricing or reduce operational costs.  
- Risk & Status Insights – Failed/pending transactions (e.g., Deposit failures) highlight potential process issues or fraud risks.  
- Operational Efficiency – Avg transaction value (₹9.02K) and small YoY declines in fees/tax indicate stable unit economics; ongoing monitoring avoids margin erosion.
